# MilkyMist Website

## Run the website
1. Extract `MilkyMist-Website.zip`.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Double-click `index.html` to open it in a browser. For the best experience, use VS Code with the Live Server extension.

## Included
- White background and black typography with a responsive design.
- Welcome splash screen that disappears after 2 seconds.
- Looping, muted `assets/main1.mp4` hero video with an ice-cream quote overlay.
- Product cards, add-to-cart, quantity changes, remove items, and cart total.
- Checkout form for name, phone, optional email, and delivery address.
- WhatsApp order message addressed to `+91 93902 48114`.

## Important
- The WhatsApp message is pre-filled; the customer must press **Send** in WhatsApp to submit the order.
- This is a front-end demo. It does not save orders to a database or process payments.
- Replace the sample products/prices in `script.js` with your actual catalogue.
- Keep `assets/main1.mp4` in the assets folder so the video loads.
